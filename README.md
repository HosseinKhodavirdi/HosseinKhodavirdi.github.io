# Hossein Khodavirdi — professional portfolio

A responsive, dependency-free academic and engineering website for GitHub Pages.

## Preview
Open index.html in a browser. No installation or build is required.

## Publish using the GitHub website
1. Sign into your personal GitHub account: HosseinKhodavirdi.
2. Create a public repository named exactly HosseinKhodavirdi.github.io. If it already exists, inspect its contents before replacing anything.
3. Upload index.html, .nojekyll, and README.md to the repository root. Commit the files.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and / (root), then Save.
7. Wait for the Pages deployment to finish. The intended website URL is https://HosseinKhodavirdi.github.io/

This package has not been pushed to GitHub or published.

## Editing
All text and styling are in index.html. Edit its text in VS Code and push changes to main. CSS variables near the start control colors. Navigation links must match section IDs.

## Checks
The page has no external libraries, fonts, tracking, or image dependencies. It includes responsive layouts, semantic landmarks, keyboard focus styles, a skip link, reduced-motion support, and print styling. Abstract wave artwork is decorative and is not simulation data.
