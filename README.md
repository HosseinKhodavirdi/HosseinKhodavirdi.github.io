# Hossein Khodavirdi — academic and professional website

A responsive, multi-page portfolio for GitHub Pages. All site files are at the repository root, so they can be uploaded together through GitHub's web interface.

## Pages and files

- `index.html` — home
- `about.html` — professional profile
- `research.html` — selected projects and methods
- `experience.html` — appointments and education
- `publications.html` — selected publications and Google Scholar link
- `contact.html` — professional profiles and CV
- `site.css` — shared design stylesheet
- `robots.txt` and `sitemap.xml` — crawler access and page discovery
- `cv.pdf` and `Hossein.jpg` — existing files; keep your preferred current versions

## Publish on GitHub Pages

Upload the HTML pages, `site.css`, `robots.txt`, `sitemap.xml`, and `README.md` to the repository root, then commit. Keep your current root-level `Hossein.jpg` and latest `cv.pdf` in place. The CSS file is at the root too, so no folder upload is needed.
